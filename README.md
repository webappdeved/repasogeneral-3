Repaso General en C++

Descripción del proyecto

Este proyecto corresponde a la Actividad 6 del Laboratorio de Programación. Consiste en un programa desarrollado en C++ que permite repasar y aplicar conceptos fundamentales de programación mediante tres retos prácticos.

Objetivos

*Comprender el funcionamiento de la recursividad.
*Aplicar la búsqueda secuencial en arreglos.
*Utilizar punteros para acceder y modificar valores en memoria.
*Practicar la compilación y ejecución de programas en C++.
*Organizar un proyecto utilizando buenas prácticas de programación y control de versiones.

Retos del programa

Reto 1: Recursividad

Implementar una función recursiva para realizar una suma, utilizando un caso base que permita detener las llamadas.

Reto 2: Búsqueda secuencial

Buscar un número dentro de un arreglo, recorriendo sus elementos hasta encontrarlo o comprobar que no existe.

Reto 3: Punteros

Intercambiar los valores de dos variables mediante el uso de punteros y una variable temporal.

Tecnologías utilizadas

*Lenguaje: C++
*Editor: Visual Studio Code
*Compilador: g++ mediante MSYS2
*Control de versiones: Git
*Repositorios remotos: GitHub y GitLab

Requisitos

Para compilar y ejecutar el proyecto se necesita:

*Tener instalado Visual Studio Code.
*Tener instalado y configurado el compilador g++.
*Disponer de una terminal compatible con los comandos utilizados.

Compilación

Desde la terminal de VS Code, ubicada en la carpeta principal del proyecto, ejecutar:

g++ src/main.cpp -o src/repasogeneral.exe

Ejecución

En Windows PowerShell, ejecutar:

.\src\repasogeneral.exe

Documentación

En la carpeta docs se encuentran los manuales de usuario y de programador, junto con el informe del cuestionario técnico.

La carpeta capturas se utiliza para guardar las evidencias de ejecución y los diagramas solicitados en la actividad.
